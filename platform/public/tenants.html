Register your Entra ID App

Register an application in the Microsoft Entra admin center for your organization.

  1. Go to Entra ID → App registrations
  2. Click New registration
  3. Name it something like Copilot Connector – [YourOrg]
  4. Set Supported account types to "Single tenant"
  5. Under API permissions, add these Microsoft Graph Application permissions:
    • ExternalConnection.ReadWrite.OwnedBy
    • ExternalItem.ReadWrite.OwnedBy
  6. Generate a Client secret and save it securely

Store Credentials in Key Vault

Store your client secret securely in Azure Key Vault. Never commit secrets to source control.

  1. Open your Azure Key Vault
  2. Create or select a vault in your subscription
  3. Add a new secret named CopilotConnector-ClientSecret
  4. Paste the client secret value you generated in Step 1
  5. Configure your connector's environment to read from this vault: 
    AZURE_KEYVAULT_URI=https://your-vault.vault.azure.net/
CLIENT_SECRET_NAME=CopilotConnector-ClientSecret

Grant Admin Consent

An Azure AD Global Administrator must grant consent for the Graph API permissions.

  1. Go to Entra admin center → App registrations
  2. Select your registered app
  3. Navigate to API permissions
  4. Click Grant admin consent for [Your Organization]
  5. Confirm the consent dialog

After consent, you should see green checkmarks (✅) next to each permission indicating "Granted for [Your Organization]".

Deploy Your First Connector

Your tenant is ready! Now deploy a connector to start ingesting content into Microsoft 365 Copilot.

  1. Go to the Observatory to see available connectors
  2. Register a connector for this tenant via the API: 
    POST /api/tenants/{tenantId}/connectors
{
  "connectionId": "my-connector",
  "displayName": "My First Connector",
  "hostingType": "azure-functions"
}
  3. Configure the connector environment variables with your Entra app credentials
  4. Deploy and trigger the first full crawl

⚠ Deactivate Tenant

This will deactivate the tenant and set all associated connectors to offline.

Data will be retained for a 30-day grace period. After that, it may be permanently deleted.

This action cannot be easily undone.
